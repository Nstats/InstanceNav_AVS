# CoIN 配置对齐与离线标定

导航默认值：描述探索关闭、`match_strict_no`、FMM 内部停止距离。
节点次数配置位于 `configs/dataset_categories.py`，停止距离配置位于
`configs/coin_contextnav.yaml`。最终默认：**1 次、FMM 0.75 米，无类别覆盖**。
官方成功距离仍为 0.25 米、预算 500 原子动作，传感器与智能体几何保持官方配置。
官方出处：<https://github.com/intelligolabs/CoIN/blob/master/config/experiments/uncertainty_objectnav_hm3d.yaml>。

GLIP 词表、顺序和附加词保持不变。内部映射为 tv→tv_monitor、
dresser→chest_of_drawers、window glass→window、hanging clothes→clothes、
heater→radiator、armchair→chair；其余类别保留。
plant、tv_monitor、book 走场景图目标分支。只有 CoIN book 节点豁免 0.4 米
跨度过滤，点数、置信度、去噪与检测次数条件仍生效。
每个任务明确设置节点门槛，不继承上一任务的值。

原始类别用于检测索引、任务标识和结果，内部类别用于匹配与分支。
采集事件另存 `canonical_category`，运行 manifest 保存映射、节点门槛和停止规则。
历史采集的 `match` 回答保留原版本。

## 重放命令

输入默认为 `20261108_181523_1477518` collect-only r1/r2，各 100 次执行、共 47
个不同目标实例。r3 无完成任务，不计入。

```bash
export PYTHONPATH=habitat-lab:.:GLIP
PYTHON=python
$PYTHON tools/coin_calibration.py --stage audit --gpu 0
$PYTHON tools/coin_calibration.py --stage nodes --gpu 0
$PYTHON tools/coin_calibration.py --stage stops --gpu 0
$PYTHON tools/summarize_coin_calibration.py
```

仅重放已有轨迹和局部锁定后的导航，不启动新的完整测评，不调用语言模型。
可在不同 GPU 上启动同一 stage：文件锁分配任务，已完成且版本匹配的结果跳过。
中断后使用同一命令继续；`--limit 1 --episode 446` 用于单任务检查。
默认输出 `outputs/coin_calibration_20261109/`，用 `--out` 修改。
输出目录对应一次标定快照。改变类别映射、权重、几何或重建逻辑时，使用新的
`--out` 目录并从 audit 开始；同目录续跑只用于完成同一版本的计算。

- `audit/` 核对动作预算、位姿、保存的 RGB/深度和原评测器 DistanceToGoal。
  使用原距离缓存语义；位姿/真实距离容差 2 毫米，朝向 0.02°。
  另报图像非完全相同帧数及差异。失败任务不进入拟合。
- `nodes/` 逐帧重跑 GroundedSAM 和三维对象合并，比较 1–5 次门槛。
  使用对齐后的内部类别和书籍尺寸规则，动作轨迹固定为旧采集轨迹。
  `.history.jsonl.gz` 保存每步节点历史。按完全相同输入缓存模型输出，缓存不含 GT。
  点云原有的随机扰动/采样保留，离线按执行标识固定种子，避免并行分配和续跑顺序影响结果。
  原运行未保存点云随机状态，因此这些是重新生成的节点历史，不是原节点的逐值恢复。
- `stops/` 使用真实 PSG 控制器，比较 FMM 0.25/0.5/0.75/1.0 米及欧氏 0.75 米。
  局部续跑固定历史目标位置，执行地图、路径与停止控制。
  只从控制状态可确定的时刻续跑：前一步在靠近候选、没有受困恢复/随机目标，
  当前移动至少 0.08 米。其他时刻明确排除。遇到 STOP、解锁、重新探索边界或
  原任务预算耗尽即结束分支。

## 指标与选值

真值只由离线工具评分。节点标签要求掩码内同一非结构物体占比至少 50% 且类别相容；
墙/地板/错类记为错误，未标注区域记为未知。同类别真实干扰物节点是有效节点。
标签随实际三维检测合并，不用未来标签改写节点首次准入结果。
精确率按真实/错误节点计算，召回按本轨迹可见的非结构实例计算（至少 25 像素），
也包括没有输出检测结果的帧。目标节点首次可用步数另报。
局部续跑的确认正确/错误分组按历史候选框中占比最高的非结构语义实例判断；
逐分支记录同时保存像素占比，便于复查遮挡和混合物体的框。
成功仍按官方停止位置距离评分，因此候选身份判断错误也可能满足官方距离条件。

同一目标的全部起点、重复运行始终放在同一折。使用 seed 77、五折验证、按目标平均，
配对 bootstrap 5000 次计算改善的 95% 区间；下界大于零才接受调整，否则保留基准。
节点按宏平均 F1 选择，类别覆盖还要求至少 10 个不同目标且两轮都改善。
停止距离按条件性成功停止比例选择，并列比较错误 STOP 与动作数。
汇总器在完整重建完成前始终返回基准。

历史轨迹使用 `match` 和描述探索开启，新配置会改变探索和确认；plant/book 改走
场景图也可能改变预测目标位置。这些数据仅支持离线代理指标和历史锁定条件下的
局部导航结论，不代表新配置的完整成功率。完整测评由用户另行启动。

## 本轮结果

200 次轨迹、节点重建和续跑阶段核查均通过。节点门槛在 47 个目标分组的五折中
均选 1 次：宏平均 F1 从 3 次的 0.1354 提升至 0.1526，改善 95% bootstrap
区间为 [0.0139, 0.0206]；出现可用目标节点的执行数从 68/200 增至 94/200。
宏平均精确率从 0.3393 降至 0.2955，召回从 0.0861 升至 0.1048；这是召回与
精确率之间的取舍，不代表导航 SR 已提高。没有类别满足相对统一值再单独覆盖的条件。

局部续跑从 127 次执行中提取 241 个可恢复确认事件，涉及 38 个目标；970 个事件
因控制状态不可恢复而排除。另 4 次执行在恢复状态后出现极小的像素/深度差异；
尽管未超容差，仍严格排除对应 11 个事件，只使用 196 次观测逐值一致的执行，
其中 123 次提供 230 个确认事件。FMM 0.25 和 0.75 米各成功 30 次，分组成功比例
改善区间为 [0, 0]，因此保留 0.75 米。0.25 米错误 STOP 较少（123 对 132），但
碰撞更多（709 对 602），平均动作更多（27.8 对 24.9）。旧欧氏 0.75 米对照成功
33 次、错误 STOP 140 次；这些对照不支持宣称 FMM 对齐能直接提高完整导航 SR。

完整结果见 `outputs/coin_calibration_20261109/report.md`，机器可读指标和分组见
同目录 `summary.json`，输入校验和见 `calibration_manifest.json`。
